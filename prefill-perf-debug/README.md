# prefill-perf-debug

Thin loader for the prefill perf runbook: `~/debug-docs/PREFILL_PERF_RUNBOOK.md` (method, traps, lever catalogue)
and `~/debug-docs/prefill_perf_tools/` (the scripts). The skill only makes Claude read the runbook and hold to its
gates; humans should read the runbook directly.

v1 (an automated level 0-3 funnel CLI, `ppd.py` and friends) was retired in favor of the runbook; it is in git
history at 734c314.
